Подробное описание

Прокси безопасности – реализует тот же интерфейс, что и реальный менеджео

Все настройки (стратегия аварий, пороги) передаются через конструктор. Дополнительные методы (isEmergencyMode) – приватные, для внутреннего использования

◆ calculateCommands()

std::map< std::string, int > SafetyProxyManager::calculateCommands ( const std::map< std::string, double > & currentReadings)
overridevirtual

Рассчитать управляющие команды для устройств

На основе текущих показаний датчиков и ранее установленных целевых параметров вычисляет, какие устройства и с какой мощностью должны работать.

Аргументы
currentReadingsТекущие показания всех датчиков (параметр -> текущее значение)
Возвращает
std::map<std::string, int> команда -> мощность Ключ: тип устройства ("heater", "conditioner", "air_humidifier" и т.д.) Значение: уровень мощности в процентах (0-100)
Заметки
Положительное значение для устройства означает "включить с указанной мощностью" Значение 0 означает "выключить устройство"

Замещает IClimateManager.

Установить целевые параметры микроклимата

Задает желаемые значения параметров, к которым система должна стремиться. Ключи — имена параметров ("temperature", "air_humidity", "soil_moisture").

Аргументы
targetsАссоциативный массив параметр -> целевое значение
Заметки
Целевые параметры сохраняются внутри менеджера и используются при каждом вызове calculateCommands().
